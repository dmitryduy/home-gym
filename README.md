# Домашний зал

План домашних тренировок на 12 недель (3 раза в неделю по часу) для двух человек: скамья, гантели, резинки, турник и брусья.

- План по этапам: от новичка до среднего уровня.
- Плеер тренировки: подход за подходом, таймеры отдыха, короткие видео техники.
- Галерея из 71 упражнения с фильтрами.

Статический сайт без сборки. Локально:

```sh
python3 -m http.server 8765
```

Видео YouTube не встраиваются, если открыть `index.html` как файл, — нужен сервер.

## Ролики

- `tools/find-videos.mjs` подбирает короткие ролики и пишет `js/videos.js`.
- `tools/check-embeds.mjs` проверяет, что ролики проигрываются во встроенном плеере (нужен запущенный локальный сервер).
